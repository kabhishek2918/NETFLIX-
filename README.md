# Cineora

Cineora is a movie and entertainment discovery platform built with the MERN stack.

## Product direction

Cineora helps users discover movies and series, explore details, build watchlists, read original reviews, and find official viewing options.

The platform is intended to be free for users, with potential revenue from compliant advertising, affiliate referrals, and sponsorships.

## Current technology

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Authentication:** JWT and bcrypt
- **Movie metadata:** TMDB integration (commercial use requires the appropriate licence)
- **Deployment:** Vercel (frontend), Render (backend)

## Important content and licensing notes

Cineora must only embed, host, distribute, or link to video content in ways authorised by the relevant rights holders and providers. Movie metadata, posters, and images must be used under the applicable provider terms and licences. Do not upload or distribute copyrighted films without permission.

## Development

Install dependencies in the backend/root and frontend folders as configured by the project, then run the backend and Vite development server in separate terminals.
